# Лабораторная работа №5: EDU OS

Реализованы пункты 1 и 2: загрузочная программа на ассемблере x86 выводит
ASCII-логотип и название EDU OS, затем ведёт простой диалог с пользователем.

## Запуск

Нужны GNU Binutils (`as` и `ld`), Make и QEMU (`qemu-system-i386`).
В текущем окружении они уже установлены. Исходник использует GNU Assembler
с Intel-синтаксисом; NASM не требуется.

Из папки `lab5` выполни:

```bash
make run
```

Откроется окно QEMU с логотипом и вопросом. Для выхода закрой окно.
После изменения исходника закрой QEMU и снова выполни `make run`.

- `make` — только собрать образ `os.img`.
- `make clean` — удалить результаты сборки.

## Диалог

После загрузки появится вопрос `Do you like assembly? [y/n]`.
Переключись на английскую раскладку и нажми клавишу в окне QEMU:

- `y` или `Y` — ответ `Great! Let's learn more.`.
- `n` или `N` — ответ `That's OK. Keep trying!`.
- Другая клавиша — подсказка `Please press Y or N:` и повтор ввода.

Enter нажимать не нужно: программа читает одну клавишу. Принятый ответ
отображается рядом с вопросом или подсказкой. После ответа программа
останавливается; для нового диалога перезапусти QEMU.

## Как устроена программа

1. QEMU запускает виртуальный компьютер с BIOS и нашим образом диска.
2. BIOS загружает первый сектор в память по адресу `0x7C00`.
3. Программа устанавливает сегменты и стек, затем включает текстовый режим.
4. `print_string` выводит строки через прерывание BIOS `0x10`.
5. Прерывание BIOS `0x16` ожидает клавишу и возвращает её ASCII-код в `AL`.
6. Команды `cmp` и условные переходы выбирают ответ или повтор ввода.
7. После ответа программа выполняет `hlt` с отключёнными прерываниями.

`boot.asm` содержит весь код и строки. В `logo` находится рисунок,
в `title` — название, в `question` — вопрос. `\r\n` переводит курсор
на начало следующей строки, а нулевой байт обозначает конец строки.

Makefile сначала собирает объектный файл `boot.o`, затем компонует его
с учётом адреса загрузки `0x7C00` в плоский двоичный образ `os.img`.
Размер образа — 512 байт. Последние два байта — `55 AA`, загрузочная
сигнатура BIOS. Директива `.org 510` оставляет место для этой сигнатуры;
слишком большой код или логотип вызовет ошибку сборки.
